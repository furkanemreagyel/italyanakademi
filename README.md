# İtalyan Akademi — Coming Soon Landing Page

Single-page bilingual (TR/EN) coming-soon website for **İtalyan Akademi**, built with vanilla HTML, Tailwind CSS CDN, and vanilla JavaScript for instant deployment on GitHub Pages.

## Features

- Responsive single-page structure
- Bilingual language toggle (TR / EN) with `localStorage` persistence
- Coming-soon hero with waitlist signup form
- Core pillars section and founder note
- Zero build step, static deployment-ready

## Run locally

Open `/home/runner/work/italyanakademi/italyanakademi/index.html` directly in your browser.

## Enable GitHub Pages

1. Go to repository **Settings**
2. Open **Pages**
3. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/` (root)
4. Save changes and wait for deployment
